## 2025-01-24 - Accessibility labels for custom styled copy buttons\n**Learning:** When creating custom styled 'chips' or 'pills' that function as buttons (like copy coupon tags), they often miss standard accessibility attributes because they diverge from standard '<button>' design patterns.\n**Action:** Always verify that interactive elements disguised as stylized badges or chips include an explicit `aria-label` describing the action (e.g., 'Copy coupon code XYZ') to ensure screen reader users understand their functionality.
