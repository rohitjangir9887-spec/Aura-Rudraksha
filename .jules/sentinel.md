## 2025-02-14 - Fix Cross-Site Scripting (XSS) in Product Information Tabs Fallback Branch
**Vulnerability:** The legacy plain-text fallback formatting path in `src/components/product/ProductInfoTabs.jsx` parsed unformatted strings and constructed dynamic HTML (replacing bold markdown elements with tags). This raw resulting string was then passed directly to `dangerouslySetInnerHTML` without proper sanitization, creating a Cross-Site Scripting (XSS) vector if malicious input bypassed earlier checks.
**Learning:** Even when legacy parsing logic appears isolated to simple formats like bold markdown, dynamically reconstructing elements manually and using `dangerouslySetInnerHTML` creates a critical dependency on upstream data escaping. A single misstep turns markdown parsing into an injection vector.
**Prevention:** Whenever dynamic HTML strings must be built from user-provided text—even when applying custom parsing or basic markdown shorthands—the strings must be robustly escaped beforehand and, as a defense-in-depth measure, the final HTML output should always be validated through an HTML sanitizer like DOMPurify before insertion into the DOM via `dangerouslySetInnerHTML`.
