## 2026-09-17 - [XSS Vulnerability in dangerouslySetInnerHTML Fallback Path]
**Vulnerability:** XSS vulnerability in `src/components/product/ProductInfoTabs.jsx`. The code used `DOMPurify.sanitize` for HTML content but completely bypassed sanitization for the plain text / markdown fallback path before passing it to `dangerouslySetInnerHTML`.
**Learning:** Always sanitize the final string passed to `dangerouslySetInnerHTML` regardless of the parsing logic or conditions that generated it. A fallback path intended for "plain text" that constructs HTML tags (e.g. `<p>`, `<div>`) can easily be exploited if the original input contains malicious script tags or attributes that do not trigger the primary HTML path but are still injected.
**Prevention:** Apply `DOMPurify.sanitize` (or an equivalent HTML sanitizer) to the final generated HTML string immediately before it is used in `dangerouslySetInnerHTML`, rather than trying to sanitize the input conditionally based on content sniffing.
