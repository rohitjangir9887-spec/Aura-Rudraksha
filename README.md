# Aura Rudraksha

A standalone React/Vite implementation inspired by the supplied Aura Rudraksha reference boards.

## Run
```bash
npm install
npm run dev
```

Open the local Vite URL.

## Included
- Responsive customer storefront
- Home, Shop, Product Details, Cart, Checkout
- Local cart persistence
- Account, Orders and tracking UI
- Admin dashboard and management screens
- Rudraksha product seed data
- Supplied visual reference boards in `public/`
